# Skrip Simulasi & Visualisasi

Folder ini digunakan untuk menyimpan skrip Python (atau Jupyter Notebook) guna membuat grafik spektrum Raman, simulasi kurva Lorentzian/Gaussian, perbandingan intensitas Stokes vs Anti-Stokes, dan gambar ilustrasi untuk dimasukkan ke folder `figures/`.

## Setup Lingkungan Python

Disarankan menggunakan virtual environment agar dependensi tidak bercampur dengan sistem global:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
